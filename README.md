O sistema é uma plataforma de gestão integrada projetada para otimizar o fluxo de trabalho em bares e restaurantes. Ele atua desde a ponta do atendimento (registro de pedidos) até a entrega final (cozinha) e a retaguarda administrativa (BI e vendas).

## Qual problema ele resolve:
O software busca eliminar falhas de comunicação entre garçons e cozinheiros, além de oferecer ao gestor uma visão analítica do negócio em tempo real. Sua interface é segmentada por níveis de acesso, garantindo segurança e simplicidade no uso diário. por que foi criado e para quem ele é direcionado.

## Como usamos IA:

Prompt para o lovable: Crie um modelo com funcionamento para testes, abrindo todas as abas e testando sempre a execução
O funcionamento do sistema se dirige a um site para um gerenciamento de um bar, divide-se em uma tela para exibição de pedidos na cozinha, uma tela para os garçons realizarem os pedidos, com a inserção também de adição de produtos no estoque de produtos, cancelamento e adição de comandas (pedidos) e por fim a exibição de uma tela para o gerente, em que exiba os dados das vendas do mes para analise, fechamento de caixa, seria como um dashboard geral para controle de vendas e estoque.
As cores utilizadas devem see vermelho vinho/escuro e amarelo mais escuro
O visual deve ser algo simples, que se dividam em categorias: espetinhos, porções e acompanhamentos, bebidas sem alcool e bebidas alcoolicas, porém que contenha tambem um local para inserção de futuras categorias
O nome do estabelecimento é Espetinho da Esquina
Crie também uma pagina de login e cadastro para somente funcionarios acessarem a pagina - lembrando, a pagina deve ser para celulares e computadores, no celular o garçom realizara os pedidos e no computador sera exibido os pedidos na cozinha
Lembrando, adicione também a adição de selecionar qual funcionario fez a venda, pois nas comandasd daquele usuario/garcom so ira aparecer oque ele pediu. Porem na cozinha deve ser exibido todos os pedidos
